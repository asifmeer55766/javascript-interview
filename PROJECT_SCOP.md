# 🚀 JavaScript: Zero to Hero

Welcome to my JavaScript learning repository! This repo documents my journey from learning the absolute basics of JavaScript to mastering advanced concepts, complete with practical code examples and mini-projects for every topic.

## 📂 Repository Structure

Each folder corresponds to a module below and contains well-commented `.js` files with practical examples.

```text
javascript-zero-to-hero/
├── 01-basics/
├── 02-control-flow/
```

## 🗺️ Learning Roadmap & Progress

### 🟢 Phase 1: The Fundamentals (Zero)
- [ ] **01 - Basics**
  - Variables (`var`, `let`, `const`) & Scoping
  - Primitive Data Types (`String`, `Number`, `Boolean`, `Null`, `Undefined`, `Symbol`, `BigInt`)
  - Type Conversion & Coercion (`==` vs `===`)
  - Operators (Arithmetic, Assignment, Comparison, Logical)
- [ ] **02 - Control Flow**
  - Conditionals (`if/else`, `switch`, Ternary Operator)
  - Loops (`for`, `while`, `do...while`, `for...of`, `for...in`)
  - `break` and `continue`
- [ ] **03 - Functions**
  - Function Declarations vs. Expressions
  - Arrow Functions (`=>`)
  - Parameters, Default Parameters, and `return`
  - Callback Functions & Higher-Order Functions

### 🟡 Phase 2: Data Structures & The Browser
- [ ] **04 - Data Structures**
  - Arrays & Essential Methods (`map`, `filter`, `reduce`, `find`, `forEach`, `slice`, `splice`)
  - Objects (Properties, Methods, `Object.keys/values/entries`)
  - `Map` and `Set`
  - JSON (`JSON.stringify` & `JSON.parse`)
- [ ] **05 - DOM Manipulation & Events**
  - Selecting Elements (`querySelector`, `getElementById`)
  - Modifying HTML, CSS, and Attributes
  - Event Listeners & Event Object (`click`, `submit`, `keydown`)
  - Event Bubbling, Capturing & Event Delegation
  - Browser Storage (`localStorage`, `sessionStorage`, Cookies)

### 🟠 Phase 3: Modern JavaScript (ES6+)
- [ ] **06 - ES6 & Beyond**
  - Template Literals
  - Destructuring (Arrays & Objects)
  - Spread (`...`) and Rest Operators
  - Optional Chaining (`?.`) & Nullish Coalescing (`??`)
  - ES Modules (`import` / `export`)

### 🔴 Phase 4: Under the Hood & Async (Hero)
- [ ] **07 - Asynchronous JavaScript**
  - Synchronous vs. Asynchronous Execution
  - Callbacks & Callback Hell
  - Promises (`then`, `catch`, `finally`, `Promise.all`)
  - `async` / `await` & Error Handling (`try...catch`)
  - Fetch API & Working with REST APIs
- [ ] **08 - Object-Oriented Programming (OOP)**
  - The `this` Keyword (`call`, `apply`, `bind`)
  - Constructor Functions & Prototypes
  - Prototypal Inheritance
  - ES6 Classes (`constructor`, `extends`, `super`, `static`, Private Fields `#`)
- [ ] **09 - Advanced Concepts**
  - Execution Context & Call Stack
  - Hoisting & Temporal Dead Zone (TDZ)
  - Lexical Scope & Closures
  - Event Loop, Microtask Queue & Callback Queue
  - Debouncing & Throttling
  - Garbage Collection & Memory Leaks

### 🏆 Phase 5: Practice & Projects
- [ ] **10 - Mini Projects**
  - [ ] Counter & Color Flipper
  - [ ] To-Do List (with `localStorage`)
  - [ ] Weather App (using Fetch API)
  - [ ] Expense Tracker
  - [ ] Quiz App

## 🛠️ How to Run the Examples

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd javascript-zero-to-hero
   ```
2. **Run a file using Node.js:**
   ```bash
   node 01-basics/variables.js
   ```
3. **For DOM examples:** Open the corresponding `.html` file in your browser (or use the VS Code Live Server extension).
